# Hit Feel Tuner — настройка удара ползунками

Окно в редакторе Unity для настройки HitFeel «на ощущения». Файлы HitFeel не меняет: только значения в профиле.

## Установка
Скопируйте папку `HitFeelTuner` в `Assets/Scripts/` (папка `Editor` внутри обязательна).

## Как пользоваться
1. Меню **Tools → Egg Game → Hit Feel → Настройка удара (Tuner)**. Окно можно прикрепить рядом с Inspector.
2. **Профиль удара** — выберите профиль меча (или «Взять у игрока в сцене»).
3. Нажмите **Play**, подойдите к врагу или манекену.
4. Включите **«Бить автоматически»** — удар будет раз в секунду. Двигайте ползунки и смотрите.
5. Начните с **«Общий вес удара»** (лёгкий → обычный → тяжёлый → мультяшный), потом подправьте детали.
6. Понравилось — просто выходите из Play: **изменения в профиле сохраняются** (это ассет, а не объект сцены).
   «Запомнить текущее» / «Вернуть запомненное» — сравнить два варианта. Ctrl+Z — отмена.

## Что за ползунки
| Ползунок | Поле профиля |
|---|---|
| Замирание при попадании (мс) | hitStopSeconds |
| Враг во время замирания | targetAnimSpeedDuringStop |
| Отброс врага / Время отброса / Подброс | knockbackDistance / knockbackDuration / knockbackUp |
| Тряска камеры (сила ×) | shakePosAmplitude, shakeRollAmplitudeDeg, shakeRecoilBack вместе (×1 = 0.03 / 1.2° / 0.06) |
| Длительность тряски | shakeDuration |
| Рывок вперёд / Резкость рывка | lungeDistance / lungeDamping |
| Громкость звука удара | audioVolume |

Остальное — в раскрывающемся блоке «Все параметры профиля».

Если используется SwordCombo, это базовые значения: удары серии умножают их на свои множители
(третий удар сильнее). Настраивайте по первому удару.

## Для агента
Окно использует из HitFeel: поля `HitFeelProfile`, `HitFeelController.profile / weaponAnimator / PlayHit / PlaySwingStart`,
`KnockbackReceiver`, `HitInfo(5 параметров)`, `HitFeelTester.SimulateHit`, `CameraShake.ImpulseLocal / Local`.
Если в проекте что-то переименовано — поправить `HitFeelTunerWindow.cs`, не HitFeel. Если есть asmdef у HitFeel —
нужен Editor-asmdef для этой папки со ссылкой на него.
