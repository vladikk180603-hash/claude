# Миссия 1 — «Форт у реки» (дизайн уровня)

> Общий контекст — в `CLAUDE.md`, интерфейс — в `UI_SPEC.md`. Этот файл описывает только уровень миссии 1 и общие правила уровней.
> Пользователь не программист: всё, что делается в редакторе Unity, описывай буквальными шагами.

## 1. Идея

Маленький каменный форт на южном берегу реки. Внутри двор с Яйцом, дома, кузница (Верстак), жители. Враги приходят с трёх сторон: через каменный мост с севера, по лесной тропе с запада и по ветхому деревянному мосту с востока. Рядом с фортом есть тайная тропа, которую враги используют только со 2–3 волны.

**Что делает уровень интересным для физики Яйца:**
- Двор имеет лёгкий уклон (≈4°) **в сторону северных ворот и реки**: Яйцо постоянно хочет укатиться к воротам.
- Река за воротами = смерть Яйца (упало в воду). Обрыв за южной стеной = тоже смерть.
- Улицы внутри форта узкие (не уже 4 м, чтобы Яйцо проходило), с лестницами и поворотами.

## 2. Схема (вид сверху, север вверху, ~120×120 м)

```
                    ГОРА + ПЕЩЕРА  [SpawnCave]
                          │ дорога
  ~~~~~~~~~~~~~~~~~ РЕКА ~~╪~~~~~~~~~~~~~~~~~~~~~~ РЕКА ~~~
                    КАМЕННЫЙ МОСТ         ВЕТХИЙ ДЕРЕВЯННЫЙ МОСТ [SpawnBridge]
                          │                    │
        ┌───────────── [С. ВОРОТА] ─────────────┼──┐
        │  ┌────┐   ДВОР С ЯЙЦОМ    ┌────┐      │  │
 ЛЕС    │  │дом │      (гнездо)     │дом │      │  │   БРОД
[SpawnForest]─[З. калитка]  ·Яйцо·  ·колодец·  │  │  (мелко, медленно)
 тропа  │  │кузн│                   │каз.│      │  │
        │  └────┘     ┌────┐        └────┘      │  │
        │   карьер    │дом │      сарай/сено    │  │
        └─────────────┴────┴──[пролом в стене]───┘  │   ← тайный путь
                     ОБРЫВ (смерть Яйца)             │
              мельница-руины ←── тайная тропа вдоль берега
```

Размеры (ориентиры для серой болванки, можно менять):
- Остров: 120×120 м. Форт: ≈45×40 м. Двор: ≈20×20 м, ровное «гнездо» 6×6 м с невысоким бортиком 0.3 м в центре (Яйцо стартует в нём, но его можно вытолкнуть).
- Река: ширина ≈12 м, глубина смертельная для Яйца. Мосты: каменный 5 м шириной, деревянный 3 м.
- Улицы в форте ≥ 4 м, ворота 5 м, калитка 3 м.

## 3. Пути врагов

| Путь | Откуда | Читаемость | Особенность |
|---|---|---|---|
| **Главный** | Пещера (север) → каменный мост → северные ворота | Мощёная дорога, видна издалека | Прямой, самый короткий, главный удар |
| **Лесной** | Лес (запад) → земляная тропа → западная калитка | Хорошо натоптанная земля | Проходит рядом с ресурсными деревьями, враги могут бить игроков-лесорубов |
| **Ветхий мост** | Восток → деревянный мост → брод → восточная стена | Узкая тропа, виден мост | **Мост можно сломать** (игроки рубят/ломают), враги тогда идут бродом: он мелкий и **замедляет** |
| **Тайный** | Берег реки у руин мельницы → пролом в южной стене | **Не размечен тропой.** Намёки: сломанная изгородь, следы, пролом в стене, брошенные бочки | Используется с 3-й волны. В 2-й волне идёт один гоблин-разведчик, чтобы игроки заметили |

Правила путей:
- Враги ищут путь через NavMesh. Игроки могут перегораживать проходы стенами, враги **перестраиваются в обход**. Если пути нет совсем — орки ломают стены (что уже в ГДД). Полностью запереть Яйцо нельзя.
- Перед каждой волной над активными спавнами показываются иконки (UI), чтобы можно было планировать.

## 4. Постройки форта

Внутри (готовые, часть можно ломать/чинить): северные ворота (деревянные, ломаются), западная калитка, стены с проходами по стене (лестницы, можно ставить турели на стену, +дальность), кузница = **Верстак**, казарма, 3–4 жилых дома, колодец, сарай с сеном, карьер/каменоломня в юго-западном углу (камень для добычи). Игроки достраивают: стены, ловушки, турели и т.п.

Модульный набор (для серой болванки и последующей замены ассетами): стена прямая, угловая, башня, ворота, дом S/M, лестница, мост, забор. Каждый модуль — отдельный префаб с коллайдером-примитивом.

## 5. Жители (NPC)

- 8–12 жителей: крестьяне и курицы. **Чисто декоративные.**
- Ходят по заранее заданным маршрутам (между домами, колодцем, сараем), без сложного ИИ.
- При появлении врагов с визгом разбегаются по домам; после волны выходят.
- Враги их игнорируют. Яйцо их **не давит, а отбрасывает** (смешной отскок, без крови).
- Не синхронизируются по сети: каждый клиент крутит их локально. Не влияют на NavMesh (без NavMeshObstacle).

## 6. Ресурсы

- **Лес** (деревья): западнее форта, за стеной (опасно во время волны). Восстанавливаются через ~90 с.
- **Камень**: каменоломня внутри форта в юго-западном углу + несколько валунов у восточного брода.
- **Шестерёнки/скрап**: выпадают из врагов, ящики в домах (разбиваются).

## 7. Тайминг и волны

| | Подготовка |
|---|---|
| Перед 1-й волной | 120 с |
| Обычные волны | 60–75 с |
| Перед боссом | 120 с |

**Ранний гонг:** большой колокол у северных ворот. Удерживать `E` 3 секунды (или все игроки голосуют) = начать волну сейчас. **Бонус: золото за каждую сэкономленную секунду** (стартовое значение 2 золота за секунду на команду; вынести в настройки). Во время волны строить тоже можно.

Волны (скейл по числу игроков из ГДД):

| Волна | Состав | Откуда |
|---|---|---|
| 1 | 5 гоблинов-бегунов | Пещера |
| 2 | 8 гоблинов + 1 разведчик | Пещера + тайный путь |
| 3 | 6 гоблинов + 3 орка-пехотинца | Пещера + ветхий мост |
| 4 | 8 гоблинов + 1 громила | Лес + пещера |
| 5 | 10 гоблинов, 4 орка, шаман | Пещера + лес + мост |
| 6 | всё и со всех сторон | Все пути + тайный |
| Босс | **Орк-вождь на бронированном кабане** | Разгоняется по каменному мосту в северные ворота. Игроки ставят каменные блоки и ловушки на мосту; ломающийся мост — запасной вариант |

## 8. Условия поражения / победы

- Яйцо в реке, за обрывом, от трёх трещин (см. механику паники в `CLAUDE.md`) или от удара босса = поражение.
- Все волны и босс зачищены = победа.

## 9. Первый объём работы (серая болванка)

Делаем **только** это, без художественных ассетов:
1. Остров, река, берега, обрыв, мосты (каменный, деревянный), брод.
2. Форт из примитивов (кубы): стены, ворота, калитка, дома-коробки, лестницы на стену, двор с уклоном и «гнездом».
3. Три спавн-точки (`SpawnCave`, `SpawnForest`, `SpawnBridge`) и точка тайного пути (`SpawnSecret`).
4. NavMesh, проверка путей от каждого спавна до Яйца.
5. Ресурсные точки (деревья/камни как цилиндры/кубы).
6. Позже: декор ассетами (расставляет пользователь), жители, гонг.

Редакторный скрипт `Tools → Build Mission 1 Greybox` должен уметь пересоздавать болванку с нуля.
