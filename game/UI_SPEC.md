# Яйцо под ударом — UI-спецификация

> Документ для агента-разработчика. Общий контекст проекта (ГДД, стиль, план, решения) — в `CLAUDE.md` рядом с этим файлом: прочитай его первым.
> Пользователь не программист: всё, что делается в редакторе Unity, описывай буквальными шагами (меню → кнопка → поле → значение).

---

## 1. Принципы UI

1. **Минимум интерфейса, максимум мира.** Игра — физический кооператив от первого лица. Строительство без меню (голограмма в мире), подсказки — у предметов, а не в углах экрана. Полноэкранные меню есть только у Верстака, паузы и лобби.
2. **Игра не ставится на паузу.** Это мультиплеер: открытый рюкзак или книга Верстака не останавливают мир. Окна компактные, чтобы игрок видел, что творится вокруг. Пауза (Esc) тоже не останавливает игру, только открывает меню.
3. **Читается за полсекунды в хаосе.** Крупные формы, мало текста, иконки вместо слов, цвет дублируется формой (для дальтоников).
4. **Яйцо — главный герой и в UI.** Его индикатор стресса самый заметный и «живой» элемент HUD.
5. **Смешно, а не сухо.** Элементы подпрыгивают, пружинят, трясутся. Это френдли слоп: UI тоже участвует в комедии.

## 2. Визуальный стиль UI

Наследует стиль игры: **игрушечный мультяшный, пухлые формы, однотонные цвета с мягкими градиентами** (как Fall Guys).

| Элемент | Решение |
|---|---|
| Панели | Скруглённые «пухлые» плашки, радиус 16–24 px, толстая обводка 4–6 px тёмно-коричневого `#3B2A1E`, лёгкая тень снизу (эффект наклейки/игрушки) |
| Фон панелей | Тёплый кремовый `#FFF4DC`, полупрозрачность 90% для HUD |
| Акцент (главный) | Золото Яйца `#FFB020` → `#E07A00` (градиент) |
| Позитив / можно | Сочный зелёный `#5CCB3A` |
| Опасность / нельзя | Тёплый красный `#E8432E` |
| Нейтральный текст | Тёмно-коричневый `#3B2A1E` (не чёрный) |
| Цвета игроков | Синий `#3A8DFF`, Красный `#FF4F5E`, Жёлтый `#FFD23F`, Фиолетовый `#A45CFF` |
| Шрифт | **Rubik** (Bold/Black для заголовков и цифр, Medium для текста) — бесплатный (Google Fonts), есть кириллица. Запасной: **Nunito**. Цифры всегда с обводкой |
| Иконки | «Стикеры»: простая форма, 2–3 цвета, толстая тёмная обводка, белая подложка-контур. Без мелких деталей и фотореализма |
| Анимации | Пружинящие (overshoot / ease-out-back), 0.15–0.3 с. Появление: scale 0.8 → 1.05 → 1. Ошибка: тряска по X |

Язык интерфейса — **русский**, но все строки через одну таблицу локализации (позже добавим английский). Не зашивать текст в код и картинки.

│                              ┼ прицел                            │
│                     [E] Подобрать бревно                         │
│                                                                  │
│                                                                  │
│ [❤ HP]  [☠☠☠ нокдауны]                                           │
│ [♥♥♥]          [1][2][3][4][5]  хотбар         [🎒 7/9]           │

### 3.1 Элементы HUD

| Элемент | Где | Поведение |
|---|---|---|
| **Стресс Яйца** | Центр сверху | Горизонтальная шкала с мордочкой Яйца слева. Зелёный → жёлтый → красный. На >70% шкала и мордочка трясутся, мордочка паникует; на >90% мигает и звучит писк. Когда игрок гладит Яйцо, сыплются сердечки. Если Яйцо вне поля зрения, у края экрана стрелка-указатель в его сторону |
| **Волна / таймер** | Слева сверху | «Волна 3/6». Во время подготовки — «Подготовка 00:45», последние 10 с пульсирует. Финальная волна — «БОСС» красным |
| **Золото** | Справа сверху | Монетка + число. При подборе число подпрыгивает, «+5» вылетает и тает |
| **Напарники** | Слева, под волной | Кружки цвета игроков с ником. Состояния: норм / низкое HP (красная обводка) / никает (иконка + таймер) / призрак (полупрозрачный). Никающий напарник также отмечен маркером в мире, видимым сквозь стены |
| **Прицел** | Центр | Маленькая точка. Наведение на интерактивный объект → кольцо. На врага → красный |
| **Подсказка взаимодействия** | Под прицелом | `[E] Подобрать бревно`, `[E] Верстак`, `[Удерживать E] Поднять напарника`. Клавиша в «кнопке»-плашке. Появляется только при наведении |
| **HP** | Слева снизу | Пухлая полоска. При уроне трясётся, теряемая часть белеет и убывает с задержкой |
| **Нокдауны** | Рядом с HP | 3 иконки-сердечка/черепка: сколько «жизней» осталось в миссии |
| **Хотбар** | Центр снизу | 5 слотов инструментов/оружия (см. §4). Активный — крупнее, с золотой обводкой |
| **Рюкзак (кратко)** | Справа снизу | Иконка рюкзака + «7/9» (занято/всего). Полный → красный, тряска, тост «Рюкзак полон!» |
| **Тосты** | Справа, над рюкзаком | Короткие сообщения 2 с: «+3 дерево», «Рюкзак полон!», «Нужно 5 камня». Не больше 3 одновременно |
| **Баннеры** | Центр экрана | «УСПЕШНАЯ ЗАЩИТА ВОЛНЫ! Приготовьтесь к следующей» + гонг. «ВОЛНА 4», «БОСС ИДЁТ!». Крупно, с пружинящим влётом, 2.5 с |

### 3.2 Предмет в руках
Средний предмет (бревно, ящик) рисуется **в мире перед камерой** (как в Minecraft), а не в UI. В HUD только подсказка `[ЛКМ] Бросить • [Q] Положить` и иконка «медленно» (черепашка) рядом с HP.

## 4. Инвентарь

### 4.1 Модель данных

- **Хотбар (5 слотов)** — инструменты и оружие: руки, молоток, топор, кирка, оружие. Переключение `1–5` и колесо мыши. Пустые слоты затемнены с иконкой-замком, пока рецепт не куплен.
- **Рюкзак** — ресурсы стаками. Старт **6 слотов**, апгрейды на Верстаке: 9 → 12. Стак: 20 штук (настраивается в данных предмета).
- **Золото/скрап** — не занимают слоты, это кошелёк (счётчик в HUD).
- **Средние предметы** — не в инвентаре, только «в руках».
- **Крупные предметы** — не в инвентаре (переноска вдвоём, позже).

`ItemDefinition` (ScriptableObject): `id`, `displayNameKey` (ключ локализации), `icon`, `maxStack`, `sizeCategory` (Small/Medium/Large), `isTool`.

### 4.2 Экран рюкзака (Tab)

- `Tab` открывает и закрывает. **Мир не на паузе**, игрок может идти, но не может смотреть мышью (курсор свободен). Esc тоже закрывает.
- Компактная панель **справа** (около 30% ширины), не на весь экран: видно, что происходит.
- Сетка слотов 3 в ряд, слоты 96×96 px, количество в правом нижнем углу с обводкой.
- Наведение → всплывашка: название, количество, «Используется для: стена, турель».
- **ПКМ / перетащить за панель** — выбросить стак (предмет физически падает перед игроком, напарник может подобрать).
- Заблокированные слоты показаны с замком и подписью «Улучши на Верстаке».
- Сверху панели — счётчик «Слоты 7/9» и золото.
- Сортировки, фильтров и drag-n-drop между слотами в MVP **нет** (держим просто).

### 4.3 Подбор
- Мелочь подбирается автоматически при касании (и притягивается магнитом).
- Иконка предмета «летит» в иконку рюкзака в HUD, рюкзак подпрыгивает, тост «+1 камень».
- Рюкзак полон → предмет остаётся лежать, тост «Рюкзак полон!» (не чаще раза в 3 с).

## 5. Строительство (без меню)

Референсы: `ui_refs/build_menu_ok.png` (хватает ресурсов) и `ui_refs/build_menu_not_enough.png` (не хватает).

**Принцип:** все рецепты видны сразу, выбор одной клавишей, никакой прокрутки колёсиком и никаких строк с подсказками на весь экран.

- Строить: взять молоток и нажать `B` (повторно `B`, ПКМ или `Esc` — выйти).
- **Панель рецептов** внизу по центру: 6–8 карточек в ряд. Выбор — клавиши **`1`–`8`** (основной способ) или клик мышью по карточке. Колесо мыши листает рецепты, но не обязательно.
- **Карточка:** номер клавиши в углу, крупная иконка постройки, внизу **чипы стоимости**: иконка ресурса + `есть/нужно` (например `8/6`). Число «есть» зелёное, если хватает, **красное, если не хватает**. Если не хватает хоть чего-то — вся карточка серая и приглушённая.
- **Выбранная карточка** приподнята и увеличена, золотая рамка (красная, если не хватает ресурсов), над ней чёрная плашка с названием постройки. Название показывается ТОЛЬКО у выбранной.
- **Голограмма** в мире: зелёная = можно поставить, красная = нельзя (мало ресурсов или место занято).
- **Запас ресурсов** — слева внизу, 3 плашки «иконка + число» (дерево, камень, шестерёнки), видны всегда в режиме стройки. Если ресурсов нет совсем, плашка серая.
- **Подсказки клавиш** — в правом нижнем углу, только 3 строки, ключ в «кнопке»: `ЛКМ` Поставить, `R` Повернуть, `B` Выход. Показываются первые ~10 минут игры или пока игрок не использовал клавишу 3 раза, потом прячутся (в настройках можно вернуть).
- Поворот постройки: `R` на 90°. Колесо мыши рецепты не переключает, если зажата `R` (тогда можно вращать точнее).
- Нехватка ресурсов при попытке поставить: карточка трясётся, нужное число мигает красным, короткий звук «нельзя». Без всплывающего текста.
- Починка: при наведении молотком на повреждённую постройку — полоска прочности над ней (в мире) и стоимость починки в тех же чипах.

## 6. Верстак — «Книга чертежей»

- Открывается `E` у Верстака. Мир не на паузе, рядом можно видеть приближающихся врагов.
- Вид: **раскрытая книга** по центру (около 60% экрана), бумажные страницы, закладки-вкладки сверху: **Оружие • Турели • Рюкзак • Магнит**.
- Карточка улучшения: иконка, название, 1 строка описания, цена в золоте, кнопка «Купить» (большая, зелёная). Не хватает золота — кнопка серая, цена красная. Купленное — штамп «ИЗУЧЕНО».
- Покупка: штамп с пружинкой, звук монет, золото в HUD уменьшается с анимацией.
- Покупки **общие для команды или личные** — пока не решено. Начни с личных, сделай настраиваемым.
- Закрытие: Esc, E или отойти от верстака дальше 4 м.

| Экран | Содержимое |
|---|---|
| **Главное меню** | Большое Яйцо в 3D на фоне (покачивается), логотип, кнопки: «Создать игру» / «Присоединиться» / «Настройки» / «Выход» |

| **Настройки** | Чувствительность мыши, FOV, громкость (общая/музыка/эффекты/голос), язык, полноэкранный режим |
| **Победа миссии** | «ЯЙЦО СПАСЕНО!» + статистика команды (убито врагов, золото, поднятых напарников, «Сколько раз Яйцо чуть не упало») |
| **Поражение** | Яйцо разбивается (анимация в мире), затем «ЯЙЦО РАЗБИТО» + причина («Упало в пропасть») + «Попробовать снова» |

Смешная статистика в конце («Лучший толкатель Яйца в пропасть: Петя») — сильный момент для клипов, заложить данные заранее.

## 9. Управление (дефолт)

| Действие | Клавиша |
|---|---|
| Движение / прыжок | WASD / Space |
| Взаимодействие (подобрать, Верстак, гладить Яйцо, поднять напарника) | E (удержание, где нужно) |
| Атака / построить / бросить | ЛКМ |
| Хотбар | 1–5, колесо мыши |

| Режим стройки | R |
| Положить предмет из рук | Q |
| Пауза | Esc |

Все бинды — через Input System Actions (`.inputactions`), чтобы потом сделать переназначение.

## 10. Техническая реализация (Unity)

- **uGUI + TextMeshPro** (не UI Toolkit): больше примеров и проще для пошаговых инструкций новичку.
- Canvas: Screen Space – Overlay, **Canvas Scaler → Scale With Screen Size, 1920×1080, Match 0.5**.
- Отдельные Canvas: `HUD`, `Popups` (рюкзак, Верстак), `Overlay` (баннеры, виньетка), `Menus`. Статичное и часто меняющееся разносить по разным Canvas (производительность).
- **UI только слушает события, не опрашивает игру в Update.** Шина событий / C#-events: `OnInventoryChanged`, `OnGoldChanged`, `OnEggStressChanged(float)`, `OnHealthChanged`, `OnPlayerDowned`, `OnWaveStarted(int)`, `OnWaveCleared`, `OnPrepTimerTick(float)`, `OnInteractTargetChanged(Interactable)`.
- **Мультиплеер (Photon Fusion 2, Host):** UI локальный для каждого игрока и показывает данные своего игрока (`HasInputAuthority`). Общие данные (стресс Яйца, волна, таймер) читаются из сетевых объектов, которые синхронизирует хост. UI никогда не меняет игровое состояние напрямую: только отправляет действие (RPC/input), хост решает.
- Данные (предметы, рецепты Верстака, постройки) — ScriptableObjects. UI строится по ним автоматически: добавил рецепт → появилась карточка.
- Строки — через Unity Localization package (или простой словарь на первое время), ключи вида `ui.backpack.full`.
- Анимации UI — DOTween (бесплатный) или собственные корутины. Не тянуть тяжёлые пакеты без необходимости.
- Шрифт Rubik → TMP Font Asset с кириллицей (Window → TextMeshPro → Font Asset Creator, Character Set: Unicode Range `0020-007E,0400-04FF,2116`).

### Как отличить хороший референс
- Панели читаются как **наклейки/игрушки**: толстая обводка, пухлые углы.
- Иконки узнаются **по силуэту** даже в размере 32 px.
- На экране не больше 3–4 цветов плюс золото Яйца.
- HUD не закрывает центр экрана.
